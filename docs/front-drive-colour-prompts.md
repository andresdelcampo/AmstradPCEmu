# System disk colour variants

Built-in image_gen, 2026-11-14. Four colour-material edits of the approved
closed/black drive crop, using the user's Amstrad system disk photograph.
Only disk-edge pixels are transferred through the existing per-drive masks.
No generated beige surfaces or latch pixels are used in these variants.

## yellow

Use case: precise-object-edit
Asset type: photorealistic inserted 5.25 inch floppy disk colour variant for emulator front-panel compositing.
Input images: Image 1 is the EXACT approved closed drive with a fully inserted black disk, EDIT TARGET. Image 2 is ONLY the disk COLOUR reference, not a reference for drive hardware.
Primary request: Change ONLY the narrow visible charcoal-black horizontal DISK JACKET EDGE inside the insertion slit to warm bright AMSTRAD SYSTEM DISK YELLOW, like the rear-left yellow disk tab in Image 2 (approximately #e7cf31 before shading). The edge is the slim band spanning approximately x165..2005, y310..337 in the 2172x724 target, naturally hidden behind the lowered beige latch at the left. Preserve its thinness, precise outline, position, natural jacket texture and delicate top-edge reflection. This represents the coloured jacket/tab of the selected system disk fully seated flush inside the closed drive. The disk edge should look like real coloured material inside a shadowed opening, with realistic soft light and a subdued small highlight, never luminous. Retain black void immediately above/below the jacket so it still sits inside the slit. Colour must remain clearly identifiable at native cabinet scale.
Invariants: keep the CLOSED VERTICAL lowered latch, pivot, beige drive body, every recess, green activity LED, slot outline, border, grey panel, exact framing, perspective, lighting and all non-disk pixels unchanged. Do not colour the slot bevel or latch. No disk protrusion, no label, no lettering, no silver shutter, no glow, no new components. One single edited 3:1 image, same exact geometry as Image 1.
