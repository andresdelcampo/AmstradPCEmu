# PC1640

Enabled by default since 2026-11-16; the earlier `AMSTRAD_PC1640=1` switch is gone.
Still untested: the items listed under Verification.

Implemented 2026-11-15. Hover or click the cabinet's model badge and pick the
**PC 1640** nameplate under **Computer**; the **PC 1512** nameplate switches
back. The drive layout (DD, SD, SD with factory sticker, or HD20) is a separate
choice in the same menu and stays as it was. Changing the computer asks for
confirmation, then restarts the PC as the other machine in the same VM: disks,
drives and a fitted HD20 carry over. The badge then reads PC 1640.

The switch selects 86Box's own `pc1640` machine: 8 MHz 8086, 640 KiB and the
internal EGA-based video device (with its CGA/Hercules compatibility). Each
machine keeps its own NVR file and BIOS-language setting, as in upstream 86Box.
The fork adds `machine_amstrad_select()` in `m_amstrad.c` and uses the PC1512's
keyboard table for the PC1640 too, so the ISO key beside left Shift sends `2Bh`
on both.

To create a VM that starts as a PC1640, pass `-Machine pc1640` to
`scripts/prepare-vm.ps1`. The launcher still creates a PC1512; switch it from
the badge.

Firmware is already installed at `C:\Emulators\86Box\roms\machines\pc1640`:

| File | Bytes |
| --- | ---: |
| `40043.v3` | 16384 |
| `40044.v3` | 16384 |
| `40100` | 32768 |

No firmware or disk images were downloaded or changed for this task. An 86Box
machine definition plus BIOS ROMs supplies the hardware; a bootable floppy or
hard disk image supplies DOS. A special prebuilt PC1640 VM image is unnecessary.
PC1640-specific system/GEM media was not found in the installed Disks folder.

## Monitor and text appearance

By default the PC1640 behaves as one sold with the **PC-ECD** enhanced colour
monitor, as upstream 86Box hardwires: "Please wait" appears in the 200-line
8 x 8 font, then the EGA BIOS switches to 350-line text in the finer 8 x 14
font. This matches the real machine's ECD350 switch setting
([DIP switches](https://www.seasip.info/AmstradXT/pc1640dip.html),
[technical manual section 1.22](https://seasip.info/AmstradXT/1640tech/contents.html)).

On a PC1640 the monitor badge opens three monitors instead of the PC1512's
colour/monochrome pair (added 2026-11-16): **PC-MD** (monochrome, 350 lines),
**PC-CD** (colour, 200 lines) and **PC-ECD** (enhanced colour, 350 lines). The
badge lettering follows the choice (`monitor-md/cd/ecd.png`), and the **?**
overlay's tag reads "Choose the screen". Unlike the PC1512's pair, the choice
is hardware: it asks for confirmation and restarts the PC
(`MainWindow::setAmstradScreen1640`).

Each card shows a test picture drawn at the monitor's own resolution
(`screenSample1640` in `qt_amstradmonitor.hpp`): the 16 fixed colours at
640 x 200 for the PC-CD, 16 colours from the palette of 64 at 640 x 350 for the
PC-ECD, a plotted curve at 720 x 350 for the PC-MD, and the line count in the
screen's own character set. A round magnified detail (`screenLens`) shows two
characters with one stripe per scan line: eight coarse rows a character at 200
lines, fourteen fine ones at 350. The 8 x 14 font is read from the machine's
own video ROM (`40100`, found by its capital A); the 8 x 8 font is the
emulator's. No downloaded or marketing pictures are used.

The choice is the video device's **Monitor** setting (also under
**Settings -> Display -> Configure**, or `monitor_type` under
`[Amstrad PC1640 (Video)]`), which stands for the rear DIP switches: `9` =
PC-ECD (default), `7` = PC-CD, `91` (0Bh with the paper-white tube) = PC-MD.
There is no separate rear-switch control: 86Box has no monitor sync
simulation, so a mismatched setting never rolls the picture, and the screen
choice and the switches are one setting. With PC-CD the real ROM keeps
200-line text, looking like the PC1512; with PC-MD it starts in mode 7
(720 x 350, 14-row characters). Both checked by booting to DOS on 2026-11-16.
The emulator still displays 350-line modes if software forces them, which a
real PC-CD could not show. Not offered: a PC-ECD starting in 200-line text
(switch value 8) and the Danish/Portuguese/Greek font switches.

Choosing a PC1640 clears the PC1512's PC-MM grey tint, which is not one of
these monitors.

## Verification

`python scripts/verify-milestone.py --machine pc1640` boots a disposable PC1640
VM offscreen and checks:

- POST banner `Amstrad PC 640K (V3.1)`, DOS boot to `A>` with the mouse driver
  V5.00 installed from the supplied disk.
- BIOS base memory of 640 KiB and the EGA BIOS signature at `C000:0000`.
- EGA mode 10h set from DEBUG: a 640 x 350 frame is displayed in the cabinet,
  then text mode 3 is restored.
- Both floppies, the cabinet menus (two computer cards and four drive layouts), then a switch
  to the PC1512 and back through the badge's handler, booting DOS each time.

Add `--shader` to run the same boot through the CRT shader in a real window.
The shader path is identical for both machines; the PC1640 picture differs
because its text mode is EGA 640 x 350 with an 8 x 14 font, not CGA 640 x 200.

The default `python scripts/verify-milestone.py` does the reverse round trip
from a PC1512. Both passed on 2026-11-15.

Not checked: mouse pointer movement in a PC1640 program (only the driver's
installation), GEM or other EGA software, the HD20 on the PC1640, and the
confirmation dialog itself (headless runs skip it). The upstream source notes
mouse-driver 7.04 compatibility problems. The monitor change through the menu
(only the three settings booted from the configuration file, and the menu's
three cards), and graphics programs on the PC-MD. This DOS's `MODE` rejects
`co80`.

- Local `upstream/86Box/src/machine/m_amstrad.c`: `machine_pc1640_init`,

## Assets

- `assets/front/badges/system-1640.png`: number-only RGBA overlay, 216 x 76.
- `assets/front/badges/system-1512.png`: matching restore overlay.
- `assets/front/badges/system-models.json`: placement and composition metadata.
- `assets/front/badges/pc1640-dd-preview.png`: badge composited over native art.

Place either overlay at **870, 1164** on the 1254 x 1254 cabinet. Only local
pixels x=53..118, y=23..48 are opaque. The red PC, DD/SD/HD20 suffix and
surrounding cabinet stay unchanged. The suffix patches occupy a separate area,
so the PC1640 number overlay works with all three suffixes.

After the front artwork became sharper and the plate narrower, the 1640 number
was redrawn at the native 1512 height of 21 pixels. Rebuild the overlays and
preview with `scripts/assemble-system-badge-assets.ps1`, which calls
`scripts/refresh-front-badges.ps1`. The older generated reference remains under
`local/artwork/pc1640/`; the current overlay uses an Arial Bold mask fitted to
the front artwork and restores the plate under the original digits.
