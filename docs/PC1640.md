# PC1640 feasibility and badge

Checked 2026-11-14 against the local pinned 86Box source and installed firmware.

86Box already implements the PC1640 as `machine = pc1640`. Its machine table
specifies 640 KiB RAM; it has its own BIOS and internal EGA-based video device
with CGA/Hercules compatibility. The existing presentation consumes variable
frame sizes into a 4:3 display, so its cabinet, input and floppy presentation
can be reused. A profile extension appears modest, but this is a source-level
assessment, not a completed PC1640 boot or compatibility test.

Firmware is already installed at `C:\Emulators\86Box\roms\machines\pc1640`:

| File | Bytes |
| --- | ---: |
| `40043.v3` | 16384 |
| `40044.v3` | 16384 |
| `40100` | 32768 |

No firmware or disk images were downloaded or changed for this task. An 86Box
machine definition plus BIOS ROMs supplies the hardware; a bootable floppy or
hard disk image supplies DOS. A special prebuilt PC1640 VM image is unnecessary.
PC1640-specific system/GEM media was not found in the installed Disks folder.

A future implementation should create an isolated PC1640 profile, select an
8086 at the historical 8 MHz, 640 KiB and internal graphics, then check POST,
DOS, both floppies, EGA/text mode transitions and internal mouse behavior.
The upstream source notes mouse-driver 7.04 compatibility problems. Monitor
artwork and labeling should also match the intended PC1640 monitor variant.
Existing launch/preparation scripts still default to PC1512; this task does
not enable or validate PC1640 runtime support.
