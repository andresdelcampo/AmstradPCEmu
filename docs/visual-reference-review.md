# PC1512 DD visual reference review

Reviewed 2026-11-13. This is a reference and acceptance document, not an approval of any generated artwork.

## Target to freeze before final art

Use an **Amstrad PC1512 DD with two 5.25-inch drives side by side and a PC-CM colour monitor** as the initial visual target. PC-MM monochrome is a valid separate variant. The detailed photo inspected below depicts a later red/grey-badged machine; do not mix its case with an original brown-badged model accidentally.

The user requires a production-quality static image as the project's go/no-go gate. A plausible generic beige PC, provisional concept render, or an attractive image with incorrect hardware does not pass.

## Inspected photograph

[DOS Days full PC-CM + DD photograph](https://www.dosdays.co.uk/topics/images/Amstrad_PC1512_CM2.jpg), linked from the [monitor reference page](https://www.dosdays.co.uk/computers/Amstrad%20PC1000/pics.php), was downloaded to temporary storage and visually inspected at full resolution. Temporary inspection copy: `C:\Users\adelc\AppData\Local\Temp\pc1512-dosdays-reference.jpg` (1704 × 2272 pixels; 1,006,785 bytes). The temporary path is not a production asset location.

Observed features:

- Two beige drive bezels sit side by side inside a recessed grey system-unit fascia. Each has a long black horizontal slot, a substantial vertical locking lever toward the left, and a small round activity light toward the right above the slot.
- Red POWER indicator sits above the left drive. The long lower grey label strip carries AMSTRAD/System Unit at left and PC1512 DD at right.
- Monitor has a broad cream bevel around curved CRT glass, AMSTRAD badge low left, PC-CM badge low right, and a round tilt/swivel pedestal. No front power switch is visible.
- The system case has top ventilation alongside the monitor. Keyboard is the period compact Amstrad layout with function keys down the left; mouse has two long buttons.

The photo has strong perspective, reflections, yellowing and background clutter. It is useful for identity and geometry, not a ready-made frontal skin.

## Static-image acceptance gate

1. **Identity:** exact selected case revision, Amstrad badges, PC1512 DD designation, PC-CM monitor, correct dual 5.25-inch mechanisms. No generic eject buttons, stacked drives, CD tray or PC1640 monitor.
2. **Proportions:** compare the rendered monitor-to-base width, bezel thickness, chassis height, drive spacing and pedestal against the inspected reference. Frontal projection must not stretch the machine to fill a widescreen canvas.
3. **Surface quality:** inspect at intended display resolution and 100% crop. Reject melted lettering, asymmetric vents, bent seams, inconsistent perspective and synthetic plastic texture.
4. **Usable art:** deliver a high-resolution master within the workspace, with a separate screen aperture/mask and documented fixed coordinates. Reserve separate layers for future drive levers, media and LEDs; do not paint fake running software into the permanent chassis texture.
5. **Review evidence:** supply full-machine and close-up comparisons with the factual reference. Distinguish measured dimensions from visual estimates. Passing quality requires the user's review of the actual final image; generation success alone is not acceptance.

The static gate does not need emulator functionality, motion, fabricated mechanical audio, or a complete keyboard. Those additions should not obscure the main monitor and front-fascia judgement.
